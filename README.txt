# 🌌 Mohammad Jeelani - Personal Portfolio Website

## 📌 Project Overview

This project is a modern and interactive personal portfolio website developed using **HTML, CSS, and JavaScript**.

The website presents my personal information, educational background, technical skills, projects, hobbies, achievements, and contact details in a unique futuristic design.

The main goal of this project is to create an attractive, responsive, and user-friendly portfolio that represents my skills and journey as a future software engineer.
